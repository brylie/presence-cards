# Presence Cards — public-domain source library

## Methodology and scope

This is a conservative first library of 50 short quotations, verified on 2026-08-08 against the linked Project Gutenberg reading text and the linked individual eBook page, which marks that exact eBook **public domain in the USA**.  The source-text URL is the exact edition checked; the reader link is its stable eBook landing page and the rights-evidence link is the same landing page.  “United States; assess separately elsewhere” is intentional: Project Gutenberg itself cautions that non-US reuse must be checked locally.  The selections preserve the edition’s spelling and punctuation; editorial and theological context is called out rather than flattened into wellness language.
